## 2026-05-13 - CLI Feedback & Summarization
**Learning:** For terminal-based security tools, users value immediate, actionable feedback when no results are found (e.g., permission tips) and appreciate aggregated summaries that quantify the severity of the scan (e.g., total CVEs and exploits found). Small visual cues like checkmarks for 'clean' states significantly improve the scan's scannability.
**Action:** Always include a 'Scan Summary' and actionable 'Next Step' tips in CLI tools, and use visual symbols (✓, ⚠) to highlight status changes.
