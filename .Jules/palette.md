# Palette's Journal - Critical UX/Accessibility Learnings

## 2024-05-22 - Initial Assessment
**Learning:** Found several missing accessibility and micro-UX features in both the Admin Panel and User App, specifically regarding input labeling, ARIA labels for icon buttons, and loading states for async actions.
**Action:** Implementing labels for inputs, ARIA labels for icon-only buttons, and visual feedback (loading states) for primary actions to improve the overall user experience and accessibility.
