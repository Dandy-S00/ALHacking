## 2025-05-18 - Visual Feedback for Async Actions in Admin Portal
**Learning:** In highly interactive administrative interfaces like LoneStar Luck's Admin Portal, providing immediate visual feedback for asynchronous actions (like login and player creation) is critical. Users need to know when a request is in flight to prevent double-submissions and reduce uncertainty. Linking labels to inputs with 'htmlFor' and 'id' is a fundamental accessibility win that is often overlooked in internal tools but essential for screen reader users.
**Action:** Always implement a loading state for primary action buttons that includes both a 'disabled' attribute and descriptive text changes (e.g., "Adding..." instead of just "Add Player"). Ensure every form input has a properly associated label element for baseline accessibility.
