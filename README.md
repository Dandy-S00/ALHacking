# LoneStar Luck

Unified gambling platform (Web, Android, iOS) with a separate Admin Panel.

## Structure
- `backend/`: Node.js/TypeScript Express server.
- `user-app/`: React Native (Expo) application for users.
- `admin-panel/`: Standalone React application for administrators.

## Features
- Texas-themed Games: Slots, Fish Games, Crash, Mines, Roulette, Plinko.
- Token Vault: Separate balance storage.
- Admin Panel: Player management, token loading/cashing, real-time logs.
- Scaling: Built with Node.js, PostgreSQL, and Redis.
